Diagrama de Flujo y Funcionamiento: ParkSystem

Mapeo de pantallas, interacción de usuario (formularios) y procesamiento de datos

1. Autenticación

Pantalla Inicial
Login
Vista inicial pública del sistema.
↓
Formulario / Acción
Completar Formulario
El usuario ingresa correo y contraseña, hace clic en "Entrar".
↓
Entrada / Salida de Datos
Validación en DB
IN: Credenciales.
OUT: Token de Sesión y Rol de Usuario asignado.
↓
Pantalla Principal
Dashboard
Redirección exitosa. Muestra resumen operativo y menú general.

2. Operación de Estancias

Pantalla / Listado
Módulo de Estancias
Tabla con el listado de vehículos actualmente estacionados.
↓
Formulario / Acción
Registrar Entrada
El usuario llena el campo de placa y hace clic en "Ingresar".
↓
Entrada / Salida de Datos
Generación de Ticket
IN: Placa y Hora actual.
OUT: Registro en BD asignado a un cajón.
↓
Acción del Usuario
Registrar Salida
El usuario selecciona un vehículo del listado y cobra salida.
↓
Entrada / Salida de Datos
Cálculo de Tarifa
IN: Hora de salida.
OUT: Costo calculado por tiempo e inserción en tabla de pagos.

3. Pensiones y Clientes

Pantalla / Listado
Módulo de Pensiones
Listado de contratos activos y clientes recurrentes.
↓
Formulario / Acción
Alta de Cliente
El usuario llena formulario de contacto y vincula una placa.
↓
Entrada / Salida de Datos
Registro en DB
IN: Datos personales.
OUT: Cliente y Vehículo guardados.
↓
Formulario / Acción
Renovar Pensión
El usuario asigna un periodo (meses) y registra el pago.
↓
Entrada / Salida de Datos
Actualización Vigencia
IN: Monto cobrado.
OUT: Nueva fecha de vencimiento en sistema.
